# Third Look — Three-Camera

Apart Research three-camera concept and Third Look study: spatial agreement, landmark identity, and verification labels.

## Repository status

This repository currently contains this project overview only. The design documents, study materials, source code, and test results have not yet been published here. There is no runnable implementation or installation procedure in this repository.

## Scope

The project concerns three topics:

- Spatial agreement between camera views.
- Landmark identity across views.
- Verification labels for interpreting observations.

This overview does not establish measured performance or hardware validation. Those claims require the supporting study materials and results.

## Reporting a problem

[Open an issue](https://github.com/RayPeloquin/Third-Look-Three-Camera/issues/new) with the relevant file or passage, what is wrong, and the expected correction. For experimental claims, include the supporting evidence and reproduction steps when available.
